# Autonomous Lane Detection System

## Overview
This project focuses on lane detection for autonomous driving using Deep Learning and Computer Vision techniques.

## Problem Statement
Accurate lane detection is a critical component of Advanced Driver Assistance Systems (ADAS) and autonomous vehicles. This project aims to detect road lanes under different road conditions, including curved roads.

## Dataset
- Custom dataset created from road videos
- 2000+ extracted frames
- Straight and curved lane scenarios

## Models Implemented
- CNN
- UNet
- VGG16
- HSTA-MCE

## Technologies Used
- Python
- OpenCV
- TensorFlow
- Keras
- NumPy
- Google Colab

## Results
- Lane segmentation on road images
- Curved lane detection
- Improved accuracy using HSTA-MCE
